## 经验（可复用）
1. 判活用 `os.kill(pid, 0)`；**锁文件消失** = 守护进程已发完并自清理，属正常终态，不是异常。
2. 队列尾部「待发 0 封」+ 全部行 `sent` 是完成判据；`--status` 的总行数应等于队列声明总量（本例 33），可用来校验无丢行。
3. 分支 A 下绝对不要跑 `--run --send --yes`：`cmd_run` 只在开头读一次队列，与守护进程同刻会重复投递给真实客户。
4. 空档期（两封之间隔 20+ 分钟）可把 sleep 拉到 190–198s 减少调用，仍满足 <200s 硬约束。
