## 一、核对方法（可复现）

不是「看着像不像」，是**程序化严格比对**：

```
1. 归一化：小写 → 去重音 → 只留 [a-z0-9]
2. 双向包含：a in b 或 b in a
3. 长度差 <= 10   ← 防止 `tec` 命中 `gnstechnologies` 之类的假阳性
4. 短于 6 字符的关键词丢弃（太短的词必然误杀）
```

**结果：50 / 50 全部干净，0 命中。**

```
rows: 50
clean: 50   flagged: 0
```

> ⚠️ 上一版我用的匹配器没有「长度差」约束，曾误报 12 条假阳性
> （`powertec` 命中 `gnstechnologies` 等）。本条已修正。
