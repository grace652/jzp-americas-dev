## 四、邮箱验证（SMTP 三点式探测）

### 4.1 🔴 DNS —— 关键的「邮件域 ≠ 官网域」陷阱

| 域名 | MX | 结论 |
|---|---|---|
| **`ew-ne.com`**（官网域） | 🔴 **无 MX 记录** | **仅 Web 用，不收邮件** |
| **`ew-inc.com`**（邮件域） | `10 us-smtp-inbound-1.mimecast.com` · `10 us-smtp-inbound-2.mimecast.com` | ✅ **真实邮件域（Mimecast）** |
| `usesi.com`（母集团） | `10 us-smtp-inbound-1.mimecast.com` · `10 us-smtp-inbound-2.mimecast.com` | 同一 Mimecast 基础设施 |

| 项（`ew-ne.com`） | 值 |
|---|---|
| SPF | `v=spf1 ip4:207.190.236.219/29 ip4:198.24.246.199 ip4:3.216.243.64 ip4:40.143.158.10 ip4:40.142.108.73 include:us._netblocks.mimecast.com include:spf.protection.outlook.com include:mail.zendesk.com include:spf.constantcontact.com include:spf.us.exclaimer.net ~all` |
| DMARC | `v=DMARC1; p=quarantine; rua=mailto:dmarc@ew-ne.com; ruf=...; fo=0; adkim=r; aspf=s; rf=afrf; sp=none` |

> 🔴 **SPF/DMARC 记在 `ew-ne.com`，但 MX 记在 `ew-inc.com`** —— 这是**典型的双域配置**：
> **`ew-ne.com` 用于品牌/SPF 策略，`ew-inc.com` 用于实际收发**。
> ⇒ **建档与发送必须以 `ew-inc.com` 为邮件域。**（与买家 155 Trotter & Morton、164 Prairie Central 同类陷阱）

### 4.2 探测结果（2026-09-28 实测）

```
##### ew-inc.com  MX=us-smtp-inbound-1.mimecast.com #####

  550  info@ew-inc.com             :: zen.mimecast.org Listed by PBL, see https://check.spamhaus.org/q
  550  sales@ew-inc.com            :: zen.mimecast.org Listed by PBL, see https://check.spamhaus.org/q
  550  customersupport@ew-ne.com   :: zen.mimecast.org Listed by PBL, see https://check.spamhaus.org/q
──────────────────────────────────────────────────────────────────────────────
  550  ccrjposkya@ew-inc.com       :: zen.mimecast.org Listed by PBL  ← 🔴 随机对照
  550  ssuizhrn10@ew-inc.com       :: zen.mimecast.org Listed by PBL  ← 🔴 随机对照
```

### 4.3 判定 —— 🔴 **与买家 172 同一失效类别（(l) 类）**

| 项 | 结论 |
|---|---|
| 现象 | **所有地址（含随机对照）一律 550 `zen.mimecast.org Listed by PBL`** |
| 根因 | 🔴 **Mimecast 依 Spamhaus PBL 拒收我方探测源 IP** |
| 性质 | **拒绝针对「我方源 IP」，与地址是否存在无关** |
| **三点式采信条件** | ❌ **不成立** |
| **SMTP 通道结论** | 🔴 **完全失效** |

> 🆕 本案与买家 172 共同确证 **新失效类别 (l)：Mimecast + Spamhaus PBL 源 IP 信誉拦截**。
> **判据统一为：随机对照地址亦返回同一 550 ⇒ 源 IP 级拦截，非目录级。**
> ⇒ 该类别**在 USESI / Sonepar 系（均为 Mimecast）中会重复出现**，后续遇 Mimecast MX **可直接预判不可探测**。
> **注意**：这**不构成对目标公司的负面判断**，仅说明**探测手段受限**。
