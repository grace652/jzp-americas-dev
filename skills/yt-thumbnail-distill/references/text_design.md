# 封面文字设计方法

从文章到封面文字。这是"内容 → 大字"的完整方法，
`07_design_text.py` 负责机械部分，人（或智能体）负责最后的语感判断。

---

## 核心矛盾

**文章标题是句子，封面大字是概念。**

| | 例子 |
|---|---|
| 文章标题 | 三十岁之前必看的防内耗指南 |
| 封面大字 | **内耗** |

标题要"说明白"，封面要"记住"。把标题搬上封面 = 把说明书贴在门上。

---

## 三层文字结构

参考频道的三层结构，每层职责不同：

| 层 | 位置 | 字数 | 职责 | 变化频率 |
|---|---|---|---|---|
| 上方小字 | ~23.5% 高度 | 2–6 | **栏目标识**（期数 / 专栏名） | 每期递增，格式固定 |
| **大字** | ~48% 高度 | **2–4** | **本期核心概念** | 每期全新 |
| 下方小字 | ~69% 高度 | 4–8 | 角度 / 具体承诺 | 每期全新 |

**上方小字是品牌，不是内容。** 固定格式（如「第 26 集」）让读者一眼认出货架，
降低认知成本。不要每期换花样。

## 大字的设计方法

### 第一步：找冲突，不找主题

问的不是"这篇文章讲什么"，而是"读者在这篇文章里感受到的那个**卡点**是什么"。

| 文章主题 | 主题式取名（差） | 冲突式取名（好） |
|---|---|---|
| 时间管理 | 时间管理 | **拖延** |
| 人际关系边界 | 人际边界 | **讨好** |
| 职场晋升 | 职场发展 | **天花板** |
| 情绪调节 | 情绪管理 | **内耗** |

主题是分类，冲突是体验。**封面卖的是体验。**

### 第二步：压缩成概念词，不是句子

硬性规则：

- ✅ 2–4 个字
- ✅ 名词或名词短语
- ❌ 不是句子（"为什么现代男性…"）
- ❌ 不含数字量词（"三个方法"、"五大困境"）
- ❌ 不含疑问词（"为什么"、"如何"）
- ❌ 不含泛用后缀（"…指南"、"…方法"、"…清单"）

### 第三步：优先具象

**具象词 > 抽象词**，因为具象词有画面，抽象词没有。

| 抽象（弱） | 具象（强） |
|---|---|
| 决策陷阱 | **人生大坑** |
| 情绪困扰 | **内耗** |
| 职业瓶颈 | **天花板** |
| 心理负担 | **枷锁** |

"坑""墙""锁""天花板""洞"——这些字自带画面。
在 2–4 个字里塞进一个具象字，是性价比最高的操作。

### 第四步：两类词各有各的好

| 类型 | 作用 | 例 |
|---|---|---|
| **冲突词 / 问题词** | 制造张力，让人想解决 | 内耗、困境、代价、焦虑、陷阱 |
| **承诺词 / 正向词** | 给出希望，让人想获得 | 希望、自由、清醒、松弛、破局 |

**两者交替使用**，不要连续几期都是问题词——读者会疲劳。

### 第五步：两个检验

1. **脱离正文检验**：把大字单独拿出来，还成立吗？
   - "内耗" ✅ 成立
   - "防内耗" ❌ 需要上下文才知道在防什么
2. **唯一性检验**：这个词是不是什么文章都能用？
   - "成长" ❌ 太泛，任何文章都能套
   - "天花板" ✅ 有指向

## 副标题的设计方法

下方小字的作用是**补足大字丢掉的精度**。大字越抽象，副标题越要具体。

| 大字 | 副标题 | 关系 |
|---|---|---|
| 内耗 | 停止精神消耗 | 给出解法方向 |
| 希望 | 绝境中的三个方法 | 给出具体承诺 |
| 男性困境 | 当代男性的五个难题 | 圈定人群 |

写法：**4–8 字，动词开头或人群开头，不要和上面小字重复。**

## 智能体工作流（每次都要走）

1. 拿到文章标题 + 正文
2. 跑 `07_design_text.py --title "..." --body article.md`
3. 读候选表。**不要盲选第 1 名。** 按下面的清单挑：

```
□ 是概念词，不是句子？
□ 2–4 字？
□ 有具象字或冲突字？
□ 脱离正文仍成立？
□ 不是"什么文章都能用"的泛词？
□ 和最近几期的词不重复？（避免连续用同类词）
```

4. 如果候选都不满意（尤其是需要**比喻**时），自己造一个：
   - 找文章里最痛的那个场景
   - 提取场景里的**实物**（坑、墙、锁、门、洞、绳）
   - 把它和处境组合
5. 用 `--top-label` 填栏目标识，副标题从候选里挑或自己写
6. 把最终三个字符串交给 prompt 编译器 / 渲染器

## 机械方法的边界（必须对用户说明）

`07_design_text.py` 的能力与局限，用真实数据说话——
拿参考频道的 4 期做过回溯验证：

| 文章标题 | 作者实际用的大字 | 脚本候选（前 4） | 结果 |
|---|---|---|---|
| 三十岁之前必看的防内耗指南 | 内耗 | 内耗 / 防内耗 / 内耗指南 / 指南 | ✅ 第 1 |
| 在绝望中看见希望的三个方法 | 希望 | 看见希望 / 希望 / 绝望 / 绝望看见 | ✅ 第 2 |
| 为什么现代有魅力的男性那么少 | 男性困境 | 困境 / 有魅力 / 魅力 / 男性困境 | ✅ 第 4 |
| 20–30岁最容易低估的6个高代价决定 | 人生大坑 | 代价 / 高代价 / 代价决定 / 容易低估 | ❌ 未命中 |

**结论：**

- **3/4 命中前 4 名**，其中 1 个直接是第 1 名。作为机械生成器，这是可用的。
- **未命中的那一个是"比喻"。** 作者用「人生大坑」，而标题里根本没有"坑"这个字——
  这是人从文章里**读出来的意象**，不是从字面提取的。**机械方法永远够不到这一步。**
- 所以脚本的定位是：**给一个高质量的起点，不是终点。**
  它会告诉你"这篇文章的候选概念有哪几个"，但"哪个最打动人"要靠读完全文之后的判断。
- 它还会**主动排除**明显错的（列表词、疑问句、泛用后缀），这本身就省了大量时间。

## 反例清单（见到就否）

| 反例 | 为什么不行 |
|---|---|
| 三个方法 / 五大困境 / 六个决定 | 列表标记。读者不关心数量，关心是什么 |
| 为什么现代男性… | 疑问句。封面不是标题 |
| 成长 / 认知 / 思考 | 泛到没有任何指向 |
| 内耗指南 / 情绪手册 | 泛用后缀，是标题碎片 |
| 停止内耗的5个技巧 | 太长 + 数字 + 后缀，三重问题 |
| 你 / 我们 / 大家 | 虚词，没有信息量 |
